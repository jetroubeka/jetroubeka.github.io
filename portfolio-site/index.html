// SITUATION_01 — ATELIER DE PROFESSIONNALISATION
Voy'Mathias — Site web d'agence de voyage
Développement complet d'un site web pour l'agence de voyage fictive Voy'Mathias dans le cadre d'un atelier de professionnalisation. Le site permet de consulter des séjours en Europe, de choisir une date de départ et de s'inscrire via un formulaire connecté à une base de données MySQL.

— Page d'accueil avec affichage dynamique des séjours depuis la BDD
— Page séjours avec système de filtres (pays, durée, recherche textuelle)
— Page départs avec dates et prix récupérés dynamiquement
— Formulaire d'inscription avec validation, insertion en BDD et gestion RGPD
— Connexion sécurisée à MySQL via PDO avec gestion des exceptions
HTML CSS PHP MySQL PDO RGPD ATELIER PRO B1.3
// SITUATION_02 — ATELIER DE PROFESSIONNALISATION
Doc'Mathias — Plateforme médicale de prise de rendez-vous
Développement d'une application web médicale complète Doc'Mathias permettant la gestion de rendez-vous entre patients et médecins, avec un système multi-rôles (patient, médecin, administrateur) et une interface adaptée à chaque profil.

— Système d'authentification sécurisé avec sessions PHP et hachage des mots de passe
— Espace patient : profil, prise de RDV, historique, annulation de rendez-vous
— Espace médecin : gestion du planning, créneaux bloqués, agenda sur 2 semaines
— Espace administrateur : gestion des médecins, spécialités et statistiques
— Connexion BDD sécurisée via PDO natif (requêtes préparées, gestion d'erreurs, fetch associatif)
— Formulaire d'inscription avec validation et insertion sécurisée en BDD
— Respect des bonnes pratiques RGPD sur les données personnelles de santé
HTML CSS PHP MySQL PDO Sessions Multi-rôles RGPD ATELIER PRO B1.3 B1.4
